# Módulo de Garantías Nicaragua

Proyecto para el módulo de garantías de Nicaragua.

## Objetivo

Centralizar la gestión de garantías para las operaciones en Nicaragua.

## Estado

🚧 En etapa inicial. La estructura del proyecto se irá definiendo en los próximos cambios.

## Cómo contribuir

1. Crea una rama a partir de `main` con un nombre descriptivo (por ejemplo, `mejora-reportes`).
2. Haz tus cambios y confírmalos con un mensaje claro.
3. Abre un Pull Request hacia `main` para que se revise antes de integrarlo.
